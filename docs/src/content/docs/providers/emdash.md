## Requirements

- Admin access to an Emdash website
- An API token with the scopes Media Read and Media Write

## Creating an API token

On your Emdash website go to the admin dashboard and navigate to settings on the sidebar. From the settings page click on API Tokens, then click on the Create Token button. You will be asked to give the token a name.

There will be a list of scopes you can check for the token. You will need to have the Media Read and Media Write scopes checked to use it with the extension. You can set the expiry of the token from a dropdown menu with the options of 7 days, 30 days, 90 days, 1 year or no expiry. Once you are done click on the Create Token button at the bottom of the form.

When your token is created you will be shown the value only once. Copy this value because you need to input it into the Emdash Token field when adding an Emdash provider to the extension.
